# BHOOMI Pest Image Dataset

17 actual image files sourced from the official TNAU Agritech/Expert System rice crop-protection image repository.

## Coverage
- Stem borer: 3
- Brown planthopper: 3
- Leaf folder: 3
- Green leafhopper: 2
- Gall midge: 2
- Thrips: 2
- Earhead bug: 2
- Whorl maggot: 0

## Status
These are reference/seed images, not a production computer-vision training set. Expert verification, quality filtering, source-diverse field images, labels, split design and license/permission verification are still required.
